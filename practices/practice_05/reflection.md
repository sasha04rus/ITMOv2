# Рефлексия по практике 5

Главная польза двух спецификаций проявилась до написания кода. Команды выбрали
одинаковые названия endpoint и полей, но разошлись в пределе длины: UI ожидал
100 символов, логика предлагала 128. Отличались и коды ошибок. Если бы сразу
началась реализация, эти расхождения обнаружились бы уже при интеграции.

Общий контракт сделал решение явным: 100 Unicode code points после серверного
strip, отдельная query_too_long и total как число совпадений. Уточнение про
Unicode оказалось существенным: JavaScript length считает UTF-16 units, а
Python len(str) — code points. Поэтому проверку длины оставили на сервере,
а в тестах использовали emoji, чтобы несовпадение единиц не осталось незаметным.

Человеческое вмешательство было конкретным: выбор фичи и двух независимых
агентов, затем утверждение предложенного контракта до реализации. Исходные
спецификации сохранены, а документы до кода вынесены в отдельный коммит. Так
можно проверить последовательность работы, а не доверять только финальному
утверждению, что команды всё заранее согласовали.

Spec Kit помог разделить требования, технический план и задачи. Для настолько
маленькой фичи служебных файлов получилось много; сам по себе фреймворк не
проверяет правильность поиска. Пришлось отдельно запускать unit/HTTP-тесты,
настоящий браузер и независимую проверку кода. Отчёт автора не использовался как
замена проверке: агент другой команды повторно запустил тесты логики.

Технические трудности относились и к среде: песочница блокировала localhost,
а установленный Edge закрывался при обычном запуске Playwright. Это не было
доказательством ошибки приложения. После разрешения локальных соединений и
запуска Edge через CDP проверили сквозные сценарии и сохранили реальные результаты.

В следующей похожей задаче стоит начинать с общего короткого примера запроса,
ответа и ошибки, затем сопоставлять его с обеими спецификациями. Для маленького
изменения достаточно узкого контракта и нескольких осмысленных проверок;
дополнительные документы полезны тогда, когда снимают конкретную неоднозначность.
